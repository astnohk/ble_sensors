# Sensors sending data via BLE

## grid-eye

Grid-EYE with SparkFun Pro nRF52840 Mini.


## Install

Clone this repository.

```
$ git clone https://github.com/astnohk/ble_sensors.git
$ cd ble_sensors
```

Create new venv under the repository.

```
$ python3 -m venv venv
$ source venv/bin/activate
```

Install dependencies

```
$ python3 -m pip install bleak
```
